# Project constraints
- Stack: React (Vite) + Tailwind CSS v3 + React Router. No backend.
- Persistence: localStorage only (cart, orders, inquiries, order notes).
- Data: only products in src/data/products.json. Do NOT invent products.
- No real payments. No card number fields.
- Pages: Home/Catalog, Product Detail, Cart, Checkout, Order Confirmation, Admin (CRM).
- Must handle: empty cart, no search results, unknown product ID, invalid
  checkout fields, out-of-stock items (cannot be added to cart).
- Responsive: works at 375px and 1280px widths.
- All customer/order data is fictional.
